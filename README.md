# 📰 Fake News Detection using NLP

A Machine Learning and Natural Language Processing (NLP) pipeline built in Python to automatically detect and classify news articles or headlines as **REAL** or **FAKE**.

---

## 📌 Features
* **TF-IDF Vectorization:** Transforms raw text into meaningful numerical feature matrices while removing stop words.
* **PassiveAggressiveClassifier:** Uses an adaptive, high-performance machine learning model optimized for large text datasets.
* **Interactive Predictions:** Allows users to paste custom headlines or news text to get instant real-time predictions.
* **Cloud Execution:** Lightweight architecture designed to run effortlessly in Google Colab.

---

## ⚙️ Tech Stack & Tools
* **Language:** Python
* **Environment:** Google Colab
* **Libraries:** `pandas`, `numpy`, `scikit-learn`

---

## 🚀 How to Run
1. Open the `Fake_News_Detection.ipynb` notebook in **Google Colab**.
2. Run all code cells sequentially.
3. Scroll to the interactive prompt at the bottom, enter any news headline or snippet, and view the predicted label (`REAL` or `FAKE`).
